# Madhusuthanan P — Developer Portfolio

A modern, futuristic, dark-themed personal developer portfolio built strictly using **HTML5, CSS3, and Vanilla JavaScript** (no external UI frameworks or libraries).

## Overview

- **Developer**: Madhusuthanan P
- **Specialization**: Computer Science Engineering Student | AI Engineering & Backend Developer | Java Full Stack | Problem Solver
- **Institution**: Sri Shakthi Institute of Engineering and Technology (2024–2028)
- **Tech Stack**: Pure HTML5, Modern CSS3 (Glassmorphism & CSS Grid), Vanilla JavaScript (ES6+)

## Features

- **Futuristic Aesthetic**: Deep obsidian background (`#07070e`), violet glow (`#8b5cf6`), cyber cyan highlights (`#06b6d4`), and subtle amber gold accents (`#f59e0b`).
- **GPU-Accelerated 3D Card Tilt**: Project cards dynamically tilt toward the cursor with a cursor-following radial light reflection.
- **Dual-Ring Custom Cursor**: Smooth desktop cursor trailing dot and ring with hover scaling (auto-disabled on touch/mobile devices).
- **Interactive Project Filtering**: Instant categorization for `All`, `AI & Machine Learning`, `Web & Full Stack`, and `Systems & Analytics`.
- **Experience Timeline**: Animated vertical glowing timeline showcasing Full Stack Internship at Apex I Sys Technologies, Web Development Internship at Prodigy Infotech, and Sri Shakthi Hackathon leadership.
- **Interactive Resume Modal**: In-app comprehensive resume viewer matching the 4-page reference resume with one-click print/save-as-PDF support.
- **Mobile Responsive**: Fully adaptive responsive layout with touch-friendly drawer navigation and zero horizontal overflow.
- **Accessibility & Performance**: Semantic HTML, visible focus states, ARIA compliance, and strict `prefers-reduced-motion` support.

## How to Run

Simply open `index.html` in any modern web browser or serve via:
```bash
# Python
python -m http.server 3000

# Node / npx
npx serve
```
